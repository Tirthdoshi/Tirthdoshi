# Tirth Doshi - Tantric Astro

Vedic astrology (Jyotisha) teacher, computational researcher, and author based in Ahmedabad, Gujarat, India. Founder of [Tantric Astro](https://www.tantricastro.com/), working in the classical Parashari and Jaimini lineages using True Citrapaksha ayanamsha and NASA JPL DE421 / BPHS computational standards.
